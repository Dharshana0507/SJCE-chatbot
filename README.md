# SJCE Chatbot

A simple command-line chatbot for St. Joseph's College of Engineering (SJCE) that provides information about the college, courses, facilities, and admissions.

## Features

- Interactive command-line interface
- Comprehensive information about SJCE
- Covers academics, facilities, admissions, and campus life
- Simple keyword-based response system

## Installation

1. Clone or download this repository
2. Ensure Python 3.x is installed on your system

## Usage

Run the chatbot:

```bash
python chat.py
```

Type your questions about the college and get instant responses. Type `bye` or `exit` to quit.

## Topics Covered

- **College Information**: Location, establishment year, affiliation
- **Academics**: Courses, departments, duration, exam patterns
- **Admissions**: Process, eligibility, cutoffs, scholarships
- **Facilities**: Library, labs, Wi-Fi, sports, dining
- **Hostel**: Accommodation, amenities, services
- **Campus Life**: Auditorium, gym, worship places, banking

## Example Interactions

```
You: What courses are offered?
Bot: The college offers UG and PG engineering courses.

You: Where is the college located?
Bot: St. Joseph's College of Engineering is located in OMR, Chennai, Tamil Nadu.
```

## Requirements

- Python 3.x
